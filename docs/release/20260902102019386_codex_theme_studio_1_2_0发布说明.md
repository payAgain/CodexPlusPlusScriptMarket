# Codex Theme Studio 1.2.0 发布说明

生成时间：2026-09-02 10:20

## 变更

### 1. 移除图标替换

- 删除实验性的「新对话 / 搜索 / 折叠侧边栏」图标替换功能
- 清理相关设置项、面板控件、CSS mask 规则和旧配置字段
- 不再依赖中文界面的按钮 `aria-label`

### 2. 内置默认字体

参考 `incipit-analysis` 的字体体系，插件现在自动注册一套跨主机默认字体：

- 正文 / UI：IBM Plex Serif + Noto Sans SC
- 强调：IBM Plex Serif SemiBold + Noto Sans SC SemiBold
- 代码 / 工具输出：Recursive Variable Font，锁定 `MONO=1, CASL=0, slnt=0`
- 字体资源随插件仓库发布，OFL 许可证文件一并保留
- 构建时内嵌为 data URI，绕开 Codex CSP 的 `font-src self data:` 限制
- 首次渲染即可自动生效，无需手动安装系统字体
- 面板中的自定义字体输入保留；留空时使用上述内置默认

## 升级

1. 在 Codex++ 脚本市场中更新 `Codex Theme Studio`
2. 重启 Codex 桌面端，或等待 watchdog 重新注入
3. 字体已内嵌在最终脚本中，首次渲染后自动生效
