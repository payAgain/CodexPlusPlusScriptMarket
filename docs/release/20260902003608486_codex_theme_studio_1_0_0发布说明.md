# Codex Theme Studio 1.0.0 发布说明

生成时间：2026-09-02 00:36

## 版本

- 插件：`Codex Theme Studio`
- 版本：`1.0.0`

## 功能

### 1. 深色主题预设

基于 Codex 桌面端官方 CSS 变量（`--color-background-*` / `--color-text-*` / `--color-border-*`）实现，非覆盖式换肤，官方 UI 结构不变：

- `官方默认`：一键回到未修改状态
- `墨蓝`：蓝黑基调，官方质感
- `曜石`：纯黑 OLED 友好
- `青屿`：青绿色调

### 2. 自定义强调色

覆盖 `--color-accent-blue`、`--color-background-info-*`、`--color-border-focus`、`--color-text-accent`、`--color-icon-accent` 等强调色族 token，自动派生 hover/active/soft 层级。

### 3. 圆角与超椭圆圆角

- 圆角比例：改写官方 `--codex-corner-radius-scale`（官方默认 1.25），0-2 全局生效
- 圆角形状：改写 `--codex-corner-shape` 超椭圆指数（柔和 / 官方 / 挺括）

### 4. 字体与字号

- UI 字体：改写 `--font-sans` / `--font-openai-sans`
- 代码字体：改写 `--font-mono`
- 聊天字号：改写 `--codex-chat-font-size` / `--codex-chat-code-font-size`

### 5. 图标替换（实验性）

按按钮 `aria-label` 匹配（新对话 / 搜索 / 折叠侧边栏），使用 CSS mask 替换为内置线性图标，选择器失配时无副作用。

## 使用方式

1. Codex++ 管理工具 → 脚本市场 → 安装 `Codex Theme Studio`
2. 重启 Codex 桌面端（或等待 watchdog 重注入）
3. 顶栏齿轮图标打开设置面板，选择预设与参数，所有修改即时生效并持久化到 `localStorage`
4. 选择 `官方默认` 预设或面板内「全部重置」即可还原

## 注意事项

- 颜色类修改仅作用于深色模式（`html.electron-dark` 作用域），浅色模式不受影响
- 官方更新可能调整内部 CSS 变量名或按钮 `aria-label`，届时需要跟进脚本版本
- 脚本设置存储于 `localStorage.__codexThemeStudioSettingsV1`，与 Codex 官方设置互不干扰
