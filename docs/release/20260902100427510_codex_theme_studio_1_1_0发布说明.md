# Codex Theme Studio 1.1.0 发布说明

生成时间：2026-09-02 10:04

## 版本

- 插件：`Codex Theme Studio`
- 版本：`1.1.0`

## 新增

### Claude 陶土主题

参考 `incipit-analysis` 的暖纸与暖黑视觉体系，新增一整套 Claude 风格深色预设：

- 暖黑主画布，侧栏使用更浅的炭纸色，边线和分隔线改为暖色低透明度
- 正文、次要文字和图标统一暖象牙色调
- 强调色默认使用 Claude 陶土橘 `#d97757`
- 输入卡改为抬升的暖炭面板，发送按钮和活动状态使用陶土橘
- 选区、滚动条、侧栏 hover 和主题面板同步进入暖色体系
- 预设圆角比例 `1.15x`，圆角形状 `superellipse(1.25)`

原有 `官方默认`、`墨蓝`、`曜石` 和 `青屿` 预设保持不变。

## 升级

1. 在 Codex++ 脚本市场中更新 `Codex Theme Studio`
2. 重启 Codex 桌面端，或等待 watchdog 重新注入
3. 打开顶栏主题工坊，选择 `Claude 陶土`
